# Web de Magus Vehículos

## Cómo abrirla en VS Code
1. Descomprimí el .zip y abrí la carpeta `magus-vehiculos` desde VS Code (Archivo › Abrir carpeta).
2. Instalá la extensión **Live Server** (de Ritwick Dey).
3. Hacé clic derecho sobre `index.html` › **Open with Live Server**. La página se abre en el navegador y se actualiza sola cada vez que guardás.

## Qué hay en cada archivo
- `index.html`: el contenido y los textos de la página.
- `css/estilos.css`: colores, tipografías y diseño. Los colores de la marca están arriba de todo, en `:root`.
- `js/main.js`: el año automático del pie de página.
- `img/`: el logo y las fotos. Para cambiar una foto, reemplazá el archivo manteniendo el mismo nombre.
